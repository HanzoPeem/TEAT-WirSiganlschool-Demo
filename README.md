# TEAT – ระบบบริหารจัดการการทดสอบและประเมินผล ชกท.

แผนกวิชาการสื่อสารประเภทสาย โรงเรียนทหารสื่อสาร กรมการทหารสื่อสาร

## การใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (หรือเปิดผ่าน GitHub Pages)

- **หน้า Lobby (ผู้ใช้ทั่วไป):** กรอก ยศ ชื่อ สกุล เพื่อตรวจสอบ
  - วันที่ต้องมาทำการทดสอบ ชกท.
  - ผลการทดสอบ ชกท. (หนังสือรายงานผล)
- **เจ้าหน้าที่:** กดปุ่มมุมบนซ้าย แล้วเข้าสู่ระบบบริหารจัดการ

## หมายเหตุ
- ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage / IndexedDB) ไม่ซิงก์ข้ามเครื่อง
- รหัสเข้าระบบเจ้าหน้าที่อยู่ในโค้ดฝั่งหน้าเว็บ ไม่ใช่ความปลอดภัยระดับเซิร์ฟเวอร์
- ควรตั้ง repository เป็น Private หากไม่ต้องการเปิดเผยโค้ด
